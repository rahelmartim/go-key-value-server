    The protocol

    Each command is one line of text over TCP.

    put,color,blue   # store a value
get,color        # ask for a value
color,blue       # every client receives this

    Concurrency

    One goroutine owns the store and the client list. The other goroutines talk to it through channels, so the server needs no locks for its state. Each client has a queue of 500 messages. When a slow client's queue is full, the server drops new messages for that client, so the other clients do not wait.
